# Принятые решения

| Дата | Решение |
|---|---|
| 2026-09-25 | Название проекта и домен — ecoservices.kz (ecoservice.kz занят другой компанией). |
| 2026-09-25 | Проект ведётся под брендом ТОО «ЭКОМЕКЕН», со ссылками на ecomeken.kz. |
| 2026-09-25 | Дизайн главной — вариант 3: деловой стиль + демо-панель мониторинга + блок ЦУР. |
| 2026-09-25 | Два первых сервиса: «Проверка объекта по НДТ» и «ESG-отчёт по стандарту P5». |
| 2026-09-25 | На сайте — продажа оборудования мониторинга (выбросы, вода, пыль, шум). Поставщик на сайте не называется до подписания договора. |
| 2026-09-25 | Стек: Django 5.2 LTS + PostgreSQL + шаблоны/HTMX + Docker. |
| 2026-09-25 | Хостинг — AWS Lightsail (Франкфурт), домен остаётся на hoster.kz, DNS A-записи на статический IP. Виртуальный хостинг hoster.kz не подходит (нет Python и SSH). |
| 2026-09-25 | Подать заявку в AWS Activate Founders после запуска сайта. |
| 2026-09-25 | Официальные иконки ЦУР не используются; номера целей — текстом. |
| 2026-09-25 | Сайт трёхъязычный: русский (основной, без префикса в URL), казахский (/kk/) и английский (/en/) через Django i18n; переводимый контент каталога — отдельными полями `*_kk`/`*_en` в моделях, не через .po. |
| 2026-09-26 | Ветки `develop` (текущая разработка) и `main` (продакшен, разворачивается на сервере). Слияние в `main` — только по явной просьбе. Отдельный dev-сервер пока не заводим. |
