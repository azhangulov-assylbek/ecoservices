# Первые промпты для Claude Code

Откройте терминал в папке проекта и запустите `claude`. Затем по очереди:

**1. Знакомство и проверка**
> Прочитай CLAUDE.md и docs/. Запусти тесты и сервер локально, проверь, что главная открывается
> и заявка на оборудование сохраняется. Сообщи, если что-то не работает. Ничего не меняй без моего согласия.

**2. Этап 2: данные НДТ**
> Начинаем этап 2 из docs/roadmap.md. Сделай management-команду `import_limits`, которая загружает
> технологические показатели из CSV (колонки как поля модели EmissionLimit) в выбранный справочник.
> Добавь пример CSV-шаблона без реальных значений и тесты. Значения показателей не придумывай.

**3. Этап 3: сервис проверки по НДТ**
> Спланируй этап 3 из docs/roadmap.md: модели объекта и установки, форма, логика сравнения с EmissionLimit.
> Сначала покажи план и структуру моделей, код пиши после моего подтверждения.
