# Дорожная карта MVP

## Этап 1. Каркас и главная (готово в стартовом пакете)
- [x] Django-проект, главная по дизайну варианта 3, каталог сервисов из базы
- [x] Заявки на оборудование сохраняются в базу, видны в админке
- [x] Модели базы НДТ: справочники, технологические показатели, техники
- [x] Docker, Caddy, инструкция по развёртыванию на hoster.kz

## Этап 2. Данные НДТ
- [ ] Загрузить официальные тексты справочников № 23 (2024) и № 232 (2026)
- [ ] Оцифровать таблицы технологических показателей (скрипт извлечения + ручная сверка, `verified`)
- [ ] Команда импорта из CSV/JSON в модели `ndt`

## Этап 3. Сервис «Проверка объекта по НДТ»
- [ ] Регистрация и кабинет пользователя, объекты и установки
- [ ] Форма параметров установки и фактических выбросов
- [ ] Детерминированное сравнение с `EmissionLimit`, краткий бесплатный результат
- [ ] Полный отчёт в Word (python-docx), пояснения ИИ со ссылками, статус «проверено экспертом»
- [ ] Из отчёта — переход к заявке на оборудование мониторинга

## Этап 4. Сервис «ESG-отчёт по стандарту P5»
- [ ] Модели проекта и оценки воздействий по элементам P5
- [ ] Оценка существенности, сопоставление с GRI/ISSB и ЦУР
- [ ] Выгрузка результатов для отчёта об устойчивом развитии

## Этап 5. Мониторинг
- [ ] Модели постов и измерений, приём данных по API
- [ ] Кабинет данных с графиками и сигналами о превышениях
- [ ] Подключение реального оборудования после договора с поставщиком
